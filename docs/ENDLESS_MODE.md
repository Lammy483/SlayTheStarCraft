# Endless Mode (retired as of v1.1.0)

Endless Mode was an experimental v1.1.0 feature and is no longer selectable for new games. Standard Mode is the only supported mode going forward.

Legacy Endless-mode runs are not deleted or converted. Their UI adapter is retained solely to avoid breaking historical saves; the v1.1.0 hotfix prevents repeated tooltip widget rebuilds and removes old tooltips when mission cards need replacing. Beyond that compatibility fix, Endless Mode is not actively supported or guaranteed to function.
