# Slay the StarCraft v1.2.0

This release provides a portable Windows launcher and the latest single-player campaign roguelike gameplay. StarCraft II is required and is not included in the download.

## Highlights

- New mission modifiers, unit behaviors, and campaign voice announcements.
- Improvements to campaign compatibility, map navigation, shops, consumables, and run generation.
- Improved enemy and allied unit behavior, including native in-game abilities.
- Portable launcher with automatic on-demand runtime download and saved preferences.

## Installation

Extract the ZIP, run `SlayTheStarCraft.exe`, and select **Download Data** before launching the game. See `README.md` for requirements and preferences.
