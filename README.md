# Slay the StarCraft 1.3.0

A single-player StarCraft II campaign roguelike powered by Archipelago.
Choose routes, build armies, unlock upgrades, and survive mutations, blessings,
chests, and events.

## Windows installation

1. Extract the complete ZIP into a writable folder. Do not launch the EXE from inside the ZIP.
2. Install StarCraft II with the campaign content for the missions you want to play.
3. Run `SlayTheStarCraft.exe` and select the StarCraft II installation folder if requested.
4. On first launch, click **Download Data** and allow it to complete.
5. Click **Launch Slay** to start a new run or load a saved run.

The included UI artwork is available immediately, without importing files from
an older installation. A private Python and Archipelago runtime is downloaded
on first setup; no system-wide Python installation is needed.

## Modes

- **Standard:** Branching mission paths, shops, events, and chests (both enabled by default).
- **Campaign (BETA):** Longer, constrained campaign-style progression.
- **Crew (BETA):** Persistent Terran forces between missions.

## Settings

`Config/slay_preferences.ini` can optionally set a Warp Gate hotkey. Existing
user preferences, runs, and runtime data are preserved by the update installer.
